# Vending_Machine_Simulator-Cs-
In this project, I made a 2D vending machine which displays 5 different unique types of sodas, each with their own price. User can simulate purchase by clicking on each icon of desired soda. The final cost will grow and display with each click on an icon. When user is finished they can simply exit the application from the exit button.
The code chosen for this program was C#, and was used within Windows Visual Studio Public edition. Windows Forms app was used along with .NET (8.0) Framework. BEhind the scenes shows what beginner friendly code i created this app with; douse your eyes in awe with the way i use structs for declaring public string & integer variables. Arrays that only hold a maximum of five(5) variables for your convenience. Instances of references to soda types so user can visually see the difference in each click of each button, and complex equation types to display totals.
If the max number of sodas(20) for each flavor is maxxed out, the user will be greeting with a message saying they need to stop their sugar intake and save their cash, all whilst using the messagebox.show() command in C#. Each flavor of soda is displayed using the label feature in Visual Studio; but so is the royalty-free png vending machine itself!
